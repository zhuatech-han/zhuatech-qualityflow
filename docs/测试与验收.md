## 复现命令

```sh
cd backend
mvn spotless:check test package
cd ../frontend
npm ci
npm run format:check
npm run lint
npm test
npm run build
cd ..
docker compose config --quiet
docker compose -p qualityflow-check up -d --build --wait
python3 scripts/smoke.py --allow-test-data
python3 scripts/release-check.py
git diff --check
```

需要 Python 3.10+，部署密码由 `.env` 注入。本机没有 Maven 时可使用官方 Maven 3.9 / Java 21 容器；挂载后端目录和本次专用依赖缓存，运行相同检查命令。只对专用可销毁测试部署运行实库脚本，它会建立虚构测试资料。

## 修复与验证范围

MySQL 实库首次启动暴露多段 VARCHAR 长文本超过行大小限制，改为 TEXT 后在全新卷重验。分析与验证计划组合历史另由 V3 扩展为 TEXT，并增加最长输入回归。角色权限表单修正标签关联，业务历史与字段标题使用可读名称；修复后前端再次通过格式、代码检查、测试和构建。

本版未执行外部渗透测试、大规模性能压测、真实仪器接口、生产多实例恢复、电子签名或监管认证验收。这些不属于已实现能力。发布流程检查代码敏感模式，并对实际服务日志与本机测试凭证作不泄露内容的比对；最终交付报告记录发布与清理结果。
